# Replay the known partnership mistakes with deployed continuations

2026-09-13. Exploratory. Written before the new replay outcomes. Jason's
clarification sets the purpose: competence on an uncommon but frustrating
partnership mistake. Ordinary-game prevalence is not the primary endpoint.

## Fixed inputs and selection

Use the six baseline misses in the saved 30-position sunshine gym report, the
single certain make/set case (advantage-09), and all 38 strict withholding
successes in the saved broader report. The latter are declaring-side positions
where review retained the baseline and its teacher value strictly exceeds every
offered-count alternative. These are selected diagnostic cases, not an estimate
of false-positive frequency on ordinary play.

Preserve each exact own/public request, original source coordinate, old choices,
Scheme offers, all teacher action values, and teacher world outcomes. Enumerate
every mechanically compatible hidden-hand completion with independent Python
rules; require exact support equality with every teacher action's traces. The
six misses contain 746 worlds, the withholding controls 1,170, and the certain
case three: 45 roots, 1,919 root/world pairs before checking for duplicates.
All outcomes use bid 30 and make/set only. Points do not break ties.

## Interventions

For every root and every compatible world:

1. Force each legal root action in turn, then let all four seats play ordinary
   deployed L1 to completion. This supplies each action's value under actual
   L1 continuation instead of the gym teacher's continuation assumptions.
2. Run the unchanged reviewed player on the original own/public root, then
   continue with reviewed players on the declaring team and ordinary L1
   opponents. This tests the assembled candidate.

The unchanged baseline and reviewed root choices are calculated from only their
seven own/public fields. The forced-action sweep is explicitly an examiner
intervention; it never gives the deployed player labels or hidden hands. Its
comparison between the actual reviewed root choice and baseline uses the same
ordinary L1 continuations, isolating the root decision from later reviews.
Also report the original teacher-preferred offer versus the original L1 choice
as a fixed diagnostic contrast, even if the 250 ms reviewer times out.

No player, sample budget, belief, tie-break, or reviewer cap changes during the
experiment. Baseline is L1 fixed 40/8; candidate is l1-partner-count-review.
Future requests use each actual seat's original hand and the public record,
with seed 420600 and the existing live wrapper's seed derivation.

## Measurement and scope

Per root, report full-support makes for every action, offer-versus-baseline
paired gains/losses/ties, actual reviewed choice, root-only intervention effect,
and complete reviewed-team effect. Preserve per-world changes: a positive net
gain need not mean that no world was harmed. Compare teacher and deployed
action rankings and include replayable gain/loss witnesses when present.

Summaries keep six missed cases, withholding controls, and the already-correct
certain case separate. Root means weight roots equally; pooled world counts are
descriptive and not independent-deal inference. Full enumeration eliminates
world-sampling error for these fixed roots and frozen procedures. It does not
eliminate model choice, timed-execution variation, selected-case bias, or the
explicit uniform mechanical prior's lack of pre-root behavioral weighting.

Persist the first realized decision for each exact request and full player
configuration across worlds and interventions. This freezes any timeout or
fallback as well as a completed choice. Time from unique cached calls is an
operational diagnostic, not a live arena latency estimate. Retain root call
timings separately, including failed review cost.

## Execution and verification

Up to ten concurrent continuations, two native threads per worker, and the
existing 14-second decision ceiling. Each workload slice uses the supplied
watchdog with at most 295 seconds; completed trajectories and decisions are
atomic and reusable. One interruption can discard active trajectories, while
their already saved decisions survive. Exercise an actual interrupt and verify
saved bytes are unchanged after resume.

Audit every complete record using independent Python rules, reconstruct the
hands from the pinned world and prefix, check every player request/configuration,
distinguish forced root actions from player decisions, and verify all 42 points
and make flags. Reject missing jobs, duplicate/misidentified worlds, corrupt
decisions, and incompatible resume identities. Save sources, binary hashes,
the panel, report, witnesses, and execution receipts in git; large raw traces
live outside git with hashes in the report. This experiment requires no new
native player implementation.
